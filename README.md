# Nine Nines

A browser game about running engineering at a fast-growing tech firm through system design.

Pick a role (Solutions Engineer, SRE, Security Engineer or Founder), scale the request path (CDN, load balancers, app servers, cache, database replicas) as traffic grows, respond to incidents like DDoS attacks, security breaches and cloud outages, hire specialists, and raise funding all the way to an IPO.

## Play

Open `index.html` in any modern browser. No build step, no dependencies. Saves live in your browser's local storage.

## Controls

- `−` / `+` on each tier to scale it
- Space pauses; `1`, `2`, `3` set speed (1×, 3×, 8×)
- Incidents pause the game until you pick a response
